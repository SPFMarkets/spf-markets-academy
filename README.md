# SPF Markets Academy

Build a beautiful, responsive forex academy app called SPF Markets. It needs a left-hand navigation sidebar for course modules (Pre-School, Elementary, High School). The center layout must display clean text lessons with beautiful mathematical formula styling. At the end of every lesson, place a prominent, styled call-to-action button for a Deriv broker affiliate link, followed by a multi-choice interactive quiz box.
